# Wohnungssuche Radeberger Vorstadt

Eigenständige, regelmäßig aktualisierte Suche nach Mietwohnungen in der
Radeberger Vorstadt in Dresden.

## Suchprofil

- 2 bis 3 Zimmer für zwei Personen
- höchstens 900 € Nettokaltmiete
- nur aktive Direktangebote im Stadtteil Radeberger Vorstadt
- keine Tauschwohnungen
- Kontaktweg bei jedem Angebot; ImmoScout-Mieternetzwerk wird als Paywall markiert
- Suche nach sicher identischen Zweitanzeigen mit frei zugänglichem Kontakt
- Karte und Fußweg zu Auf dem Meisenberg 19, 01099 Dresden, soweit die Lage
  verlässlich veröffentlicht ist
- Aktualisierung montags und mittwochs um 09:00 Uhr (Europe/Berlin)
